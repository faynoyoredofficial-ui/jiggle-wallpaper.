САМЫЙ ПРОСТОЙ СПОСОБ (без Android Studio):

1. Зайдите на github.com и зарегистрируйтесь (бесплатно).
2. Нажмите + → New repository, назовите как угодно, Create repository.
3. Нажмите «uploading an existing file» и перетащите ВСЁ содержимое этой папки
   (включая скрытую папку .github). Нажмите Commit changes.
   Если .github не загрузилась: Add file → Create new file, имя
   .github/workflows/build.yml , вставьте туда текст из build.yml.txt.
4. Вкладка Actions → подождите 3-5 минут, пока значок станет зелёным.
5. Откройте последний запуск, внизу в Artifacts скачайте zhivye-oboi-apk,
   распакуйте: внутри app-debug.apk.
6. Перекиньте apk на телефон, откройте, разрешите установку из этого источника.
7. В приложении: выбрать фото → закрасить → «Поставить обои».
